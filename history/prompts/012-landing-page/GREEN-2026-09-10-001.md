## Prompt

/sp.implement

Implement the public Landing Page according to the constitution, specification, plan, and tasks already defined.

### Implementation Instructions

Follow this order strictly:

1. **Foundation**
   - Create the public Landing Page route (accessible without authentication).
   - Set up the overall page structure with clear sections.
   - Establish the visual foundation: dark theme, green accents, typography, and spacing system.
   - Ensure the page is responsive from the start.

2. **Navbar**
   - Build the Navbar with logo, navigation links, and primary CTA.
   - Add sticky/fixed behavior if required.
   - Connect the CTA button to the sign-up / authentication flow.

3. **Hero Section**
   - Create a strong fitness-focused headline and supporting subheadline.
   - Add primary and secondary CTA buttons.
   - Include a supporting visual (illustration or product mockup).
   - Add subtle, purposeful animations.

4. **Core Content Sections**
   - Features section (key capabilities with icons + short descriptions)
   - How-it-Works section (clear 3–4 step flow)
   - Fitness Statistics section
   - Benefits section (focus on user outcomes)

5. **Trust & Conversion**
   - Testimonials section
   - Final CTA section with strong closing message
   - Footer (logo, important links, copyright)

6. **Polish**
   - Add smooth scrolling for internal navbar links
   - Refine spacing, visual hierarchy, and consistency
   - Optimize animations for performance
   - Perform full responsive testing
   - Final review for conversion and brand consistency

### Rules
- Keep the visual language consistent with FitTrack (dark theme + green accents).
- CTAs must correctly lead to the sign-up flow.
- Animations should enhance the experience without hurting performance.
- Code should be clean, modular, and easy to maintain.
- Follow all acceptance criteria from the specification.
