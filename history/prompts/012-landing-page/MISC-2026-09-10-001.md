## Prompt

User asked (after landing was verified working in incognito): "now do one work can u please permenently let this landing page run on normal browser without incognito" — i.e., make the landing page viewable for logged-in users in the normal browser.

## Response snapshot

- Changed `frontend/src/App.jsx` route from `<Route path="/landing" element={<PublicOnly><Landing /></PublicOnly>}/>` to `<Route path="/landing" element={<Landing />}/>`.
- Rationale: product decision by owner — landing is public for everyone; authenticated users clicking a primary CTA are handed off cleanly to the app because `/register`/`/login` are still `PublicOnly` (auths are redirected to `/`), so no dead-end or error page (covers spec edge case 1).
- Updated `quickstart.md` Gate 3 to document the new behavior (no redirect for authed users on /landing; /login//register handoff unchanged).
- Verified: `npm run build` PASS; dev server HMR reflects the change (transformed App.jsx shows `element: _jsxDEV(Landing, ...)` on the `/landing` route).
- No other route changed; `PublicOnly` import still used by `/login`/`/register`.
