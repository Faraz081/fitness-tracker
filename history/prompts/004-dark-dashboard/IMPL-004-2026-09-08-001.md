only, no TypeScript) on branch 004-dark-dashboard, tracking task-by-task against
specs/004-dark-dashboard/tasks.md (T001-T017). Match the dark reference (palette
#0b0f14/#161b22/#232a33, orange #FF8C42 base + lime accent #A3E635). No new runtime
dependencies (no chart/state libraries), mock data only. Layout: fixed left
sidebar (logo, Dashboard/Exercise/Nutrition menu + profile block at bottom), top
navbar (logo + "Fitness Tracker", center tabs Dashboard/Workouts/Nutrition/
Goals/BMI, avatar + name), main area with Quick Log buttons (Water/Steps/
Calories/Sleep/Weight/Workout). Content: personalized greeting + date; six
summary cards; daily goals progress cards; activity rings; weekly workout bar
chart; calories line/area chart; macro donut chart; recent workouts; quick
actions; empty/loading/error states; responsive at multiple breakpoints. Then
verify with a production build, mark tasks complete, create this PHR (stage:
green), and report.
