## Prompt

Context for task generation: /sp.tasks

Break down the Nutrition Search feature into clear, sequential, and implementable tasks.

### 1. Foundation
- [ ] Review existing Nutrition page structure and meal logging flow
- [ ] Confirm existing Nutrition model/API support for saving meal entries
- [ ] Identify integration points for search bar, result card, and add modal
- [ ] Confirm authenticated user scoping for saved nutrition logs

### 2. Secure Gemini Lookup
- [ ] Ensure backend support for GEMINI_API_KEY
- [ ] Create backend endpoint/service for live food nutrition analysis
- [ ] Accept natural-language food name input from frontend
- [ ] Call Gemini in real time and return structured nutrition data
- [ ] Include food name, serving basis, calories, protein, carbs, fat, fiber, sugar, sodium
- [ ] Validate AI response on the backend
- [ ] Handle unrecognized food, API failure, and missing key
- [ ] Ensure Gemini key is never exposed to the frontend

### 3. Search UI
- [ ] Add a single search bar for food name only
- [ ] Trigger live AI lookup on search
- [ ] Show loading state while Gemini is analyzing
- [ ] Render result card with food name + "AI" badge
- [ ] Show per-serving Calories, Protein, Carbs, Fat
- [ ] Show Fiber, Sugar, Sodium
- [ ] Add "+" action on the result card

### 4. Add-to-Log Modal
- [ ] Open modal when "+" is clicked
- [ ] Show food name + AI badge and close (X)
- [ ] Show nutrition breakdown
- [ ] Add editable Quantity (g) input
- [ ] Live-recalculate "For [X]g: [Y] kcal | P | C | F" from real AI data
- [ ] Add "Add To" dropdown: Breakfast / Lunch / Dinner / Snacks
- [ ] Add Cancel and + Add Food buttons

### 5. Persistence & Meal Integration
- [ ] Save entry to actual backend/database on Add Food
- [ ] Store authenticated user ID, food name, meal type, quantity, and nutrition values
- [ ] Show saved food under the selected meal section in real time
- [ ] Avoid local/session-only persistence
- [ ] Show empty state: "No food logged for [Meal]"
- [ ] Show hint: "Use AI search above to find and add foods."

### 6. Real-Time Updates & Cleanup
- [ ] Update main nutrition log after save without manual refresh
- [ ] Ensure meal sections reflect newly added food
- [ ] Remove static/placeholder nutrition behavior from this flow
- [ ] Enforce user-scoped data access

### 7. Final Verification
- [ ] Test live Gemini search results for common foods
- [ ] Test quantity changes and live recalculation
- [ ] Test save to Breakfast / Lunch / Dinner / Snacks
- [ ] Test persistence after refresh
- [ ] Test empty meal state
- [ ] Test Gemini failure / unrecognized food handling
- [ ] Test multi-user data isolation

### Recommended Order
1 → 2 → 3 → 4 → 5 → 6 → 7
