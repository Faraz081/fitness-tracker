## Prompt

/sp.implement

Implement the Final Testing & Requirements Check phase according to the constitution, specification, plan, and tasks already defined.

### Implementation Instructions

Follow this order strictly:

1. **Preparation**
   - Gather the complete original project requirements list.
   - Prepare test data for normal, empty, and edge-case scenarios.
   - Set up a simple system to mark each item as Pass / Fail / Partial.

2. **CRUD Testing**
   - Test Create, Read, Update, and Delete for Workouts, Exercises, Nutrition entries, Goals, and Profile data.
   - Verify validation messages, success states, and empty states.

3. **Authentication Testing**
   - Test Sign up, Login, Logout, session persistence, protected routes, and Change Password.
   - Confirm unauthorized users cannot access private pages.

4. **Dashboard & Charts**
   - Verify all Dashboard calculations and summary metrics with real data.
   - Test behavior with sparse/empty data.
   - Confirm Charts and Analytics render correctly and show accurate values.

5. **Feature Area Testing**
   - Test Search and Filtering (including combined filters and clear filters).
   - Test Notifications (creation, read/unread, settings respect).
   - Test Settings end-to-end (profile, units, theme, notifications, password, logout, delete account).
   - Test Reports & Export (date range, CSV, PDF accuracy and download).

6. **Responsiveness & UI Consistency**
   - Test the app on mobile, tablet, and desktop.
   - Confirm the final black + orange theme is consistent everywhere.
   - Review empty states, loaders, and error handling.

7. **Requirements Traceability**
   - Go through every original requirement one-by-one.
   - Mark each as Pass / Fail / Partial.
   - Record any missing or incomplete items.

8. **Bug Fixing & Re-testing**
   - Log all discovered bugs.
   - Prioritize and fix blockers and major issues.
   - Re-test every fixed item.
   - Re-check any previously failing requirements.

9. **Final Sign-off**
   - Confirm all critical flows pass.
   - Confirm requirements coverage is complete.
   - Confirm responsiveness is acceptable.
   - Only then mark the project as ready for delivery.

### Rules
- Do not skip requirements or assume they work.
- Test with both normal and edge-case data.
- Fix bugs before closing the phase.
- Re-test after every fix.
- Follow the acceptance criteria strictly.

Start from step 1 and proceed sequentially until final sign-off.
