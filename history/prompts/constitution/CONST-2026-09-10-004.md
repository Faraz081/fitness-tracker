## Prompt

/sp.constitution

You are defining the constitutional rules and non-negotiable principles for the Premium UI/UX Upgrade of the FitTrack application.

### 1. Purpose
This constitution governs a complete visual and interaction upgrade of the entire FitTrack application. The goal is to elevate the product to a premium, modern, and polished experience using a full black + orange design system, while improving consistency, usability, and perceived quality across every page.

### 2. Core Principles

- **Premium Feel**: Every screen must feel modern, intentional, and high-quality. Avoid generic or outdated UI patterns.
- **Complete Theme Consistency**: The entire application must adopt a full black + orange theme. No leftover green accents or mixed color systems are allowed.
- **Design System Discipline**: Cards, buttons, inputs, icons, spacing, and typography must follow one unified system.
- **Delight with Purpose**: Animations, hover effects, transitions, and loaders should enhance the experience — never distract or slow the user down.
- **Clarity & Hierarchy**: Strong visual hierarchy, consistent spacing, and readable typography are mandatory.
- **Responsive by Default**: The upgraded UI must work excellently on mobile, tablet, and desktop.

### 3. Required Capabilities (Non-Negotiable)

The upgrade must deliver:

- Complete black + orange theme across the entire app
- Modern sidebar / navigation
- Improved cards
- Improved buttons
- Consistent icon system
- Hover effects
- Smooth transitions
- Page animations
- Loading animations
- Skeleton loaders
- Toast messages
- Modal improvements
- Consistent spacing system
- Better typography
- Fully responsive design (mobile + tablet + desktop)

### 4. Technical & Design Constraints

- All existing green accents must be fully replaced with the new orange system
- Spacing, radius, shadows, and typography must be standardized
- Animations must be performant (prefer CSS or lightweight libraries)
- Skeleton loaders must be used for major data-loading states
- Toasts and modals must follow the new visual language
- No page should feel visually inconsistent after the upgrade

### 5. Design Rules

- Primary background: deep black / near-black
- Primary accent: vibrant orange
- Cards must have clear hierarchy, refined borders/shadows, and consistent padding
- Buttons must have clear states (default, hover, active, disabled)
- Sidebar/navigation must feel modern and polished
- Typography must improve readability and hierarchy
- Spacing must follow a consistent scale across the whole app

### 6. Out of Scope

- Changing core product functionality
- Adding completely new features
- Redesigning the public Landing Page from scratch (unless it also needs theme alignment)
- Heavy 3D or excessive motion design

### 7. Success Criteria

The Premium UI/UX Upgrade is considered complete when:
- The entire app uses a consistent black + orange theme
- Cards, buttons, navigation, and typography feel clearly upgraded
- Hover effects, transitions, and animations are smooth and purposeful
- Skeleton loaders, toasts, and modals are improved and consistent
- Spacing and visual hierarchy are unified
- The experience feels premium on mobile, tablet, and desktop
