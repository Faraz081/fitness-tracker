## Prompt

Create a Spec-Driven Development (SDD) constitution for Day 2.1 of the Fitness
Tracker project.

Project continues from Day 1.1 (Modern Dark Dashboard is already complete).

Day 2.1 Goal: Build the Progress & Goals section of the Fitness Tracker using
only .js and .jsx files (no TypeScript).

Features that must be fully specified: Progress page; Weight tracking; Body
measurements; Weight progress graph; Workout performance graph; Strength /
progression history; Personal goals; Goal progress bars; Goal completion status;
Milestones; Streak system.

Design & Technical Rules: keep the same modern dark theme from Day 1.1 (deep
black/charcoal, clean cards, consistent typography); use only .js and .jsx files
(strictly no TypeScript); clean, generic, production-ready React code; no
AI-looking comments or over-engineering; fully responsive; match the overall
visual language of the existing dashboard; reuse existing layout (Sidebar +
Navbar) where possible.

Constitution Requirements: 1) clear extension of the existing project structure
(do not break Day 1.1 dashboard); 2) component breakdown for the Progress &
Goals feature; 3) data shape decisions (weight entries, body measurements,
goals, milestones, streaks); 4) how graphs/charts should behave (including empty
states); 5) goal system rules (progress calculation, completion status,
milestones); 6) streak system rules (how streaks are calculated and displayed);
7) state management approach (simple and clean); 8) UI/UX rules for progress
bars, graphs, and status indicators; 9) coding standards (naming, file
organization, simplicity); 10) success criteria / Definition of Done for Day
2.1; 11) what is out of scope for Day 2.1 (backend, real API, authentication,
notifications, etc.).

Output a complete, clear, and strict constitution document that a coding agent
or developer can follow exactly to build the Progress & Goals feature.
