   states.
5. End with a final "Day 3.1 Verification" task that checks visual consistency,
   filters, detail view, and responsiveness.
6. Do not include any features marked as out-of-scope (backend, real API,
   authentication, etc.).

Output the tasks in a clean, numbered list that a coding agent or developer can
execute one-by-one.
