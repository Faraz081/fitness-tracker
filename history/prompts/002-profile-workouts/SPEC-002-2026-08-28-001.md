## Prompt

Using the Day 2 constitution for User Profile & Workout Management, create a
detailed, implementation-ready Specification (Spec) for Day 2 of the MERN
fitness/workout tracking project. Day 1 (Authentication) is complete and MUST
be reused, not rebuilt. Day 2 goals: Profile page (view + update name/profile
info); Workout model; Add Workout with exercises (sets, reps, weight, notes);
Workout List page; Edit workout; Delete workout; workout categories; test
complete Workout CRUD. Produce a precise spec covering: (1) project structure
updates (new client+server files, integration with Day 1); (2) data models —
updated User (bio, age, weight, height, goal, fitnessLevel, avatarUrl), full
Workout schema (title, category, date, notes, exercises), Exercise subdocument

(every workout references the authenticated user); (3) API spec —

owner-scoped authorization; (4) frontend spec — Profile view+edit, WorkoutList
with empty state, Add/Edit WorkoutForm with dynamic exercise rows, delete
confirmation, category dropdown, loading/error states, nav updates; (5) state

Day 2 DoD checklist; (8) out-of-scope list. Precise, unambiguous, no guessing.
