## Prompt

/sp.tasks

Break down the Search & Filtering feature into clear, sequential, and
implementable tasks.

### 1. Reusable UI Components
- [ ] Create reusable SearchInput component (matches existing design system)
- [ ] Create Date filter component (single date + date range)
- [ ] Create Workout Category filter component
- [ ] Create Meal Type filter component
- [ ] Create “Clear filters” button component
- [ ] Ensure all components use the same dark theme, green accents, and spacing as the Dashboard

### 2. Search Logic
- [ ] Implement debounced search input
- [ ] Add search for Workouts (by name and notes)
- [ ] Add search for Exercises (by name)
- [ ] Add search for Nutrition records (by food name)
- [ ] Make all search case-insensitive
- [ ] Implement Global Search that returns results from Workouts, Exercises, and Nutrition (grouped or labeled)

### 3. Filtering Logic
- [ ] Implement Date filter for Workouts and Nutrition
- [ ] Implement Workout Category filter
- [ ] Implement Meal Type filter for Nutrition
- [ ] Allow search + filters to work together
- [ ] Maintain filter/search state while user stays on the page

### 4. Clear Filters & Empty States
- [ ] Show “Clear filters” button only when any search or filter is active
- [ ] Reset search text and all filters on clear
- [ ] Create consistent empty state for “No results found”
- [ ] Empty state must include a way to clear filters

### 5. Page Integration
- [ ] Integrate search + filters into Workouts page
- [ ] Integrate search + filters into Exercises list
- [ ] Integrate search + filters into Nutrition page
- [ ] Integrate Global Search (if required in the main layout)

### 6. Final Polish
- [ ] Match visual style completely with Dashboard
- [ ] Remove any large side gaps
- [ ] Test combinations of search + multiple filters
- [ ] Test with large datasets for performance
- [ ] Final responsive and UX check

### Recommended Order
1 → 2 → 3 → 4 → 5 → 6
