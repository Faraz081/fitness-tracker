## Prompt

/sp.plan

Create a detailed implementation plan for the Premium UI/UX Upgrade based on the constitution and specification already defined.

### Goal
Upgrade the entire FitTrack application to a premium black + orange design system with modern components, refined motion, consistent spacing/typography, and strong responsiveness — without changing core product functionality.

### Phase 1: Design System Foundation
1. Define the new black + orange color tokens (backgrounds, surfaces, accent, text, borders, states).
2. Define spacing scale, border radius scale, and shadow system.
3. Define typography hierarchy (headings, body, labels, numbers).
4. Create or update the global theme configuration so the whole app can adopt it.

### Phase 2: Core Component Upgrade
1. Upgrade Buttons (default, hover, active, disabled states).
2. Upgrade Cards (padding, borders, shadows, hierarchy).
3. Upgrade Icons and icon usage consistency.
4. Upgrade form inputs and basic controls.
5. Upgrade Modals (overlay, animation, structure, hierarchy).
6. Upgrade Toast messages (style + behavior).

### Phase 3: Navigation Upgrade
1. Redesign the sidebar / main navigation for a modern premium look.
2. Improve active, hover, and focus states.
3. Ensure the navigation remains clear and consistent across all pages.

### Phase 4: Motion & Feedback
1. Add refined hover effects on interactive elements.
2. Implement smooth transitions for common state changes.
3. Add subtle page transition / enter animations where appropriate.
4. Implement loading animations for key actions.
5. Implement skeleton loaders for major data-loading states.

### Phase 5: Global Application
Apply the upgraded system across all major pages:
- Dashboard
- Workouts
- Nutrition
- Progress / Analytics
- Goals
- History
- Profile
- Settings
- Notifications
- Reports

Ensure no page is left with old green accents or inconsistent styling.

### Phase 6: Spacing, Typography & Responsiveness
1. Apply consistent spacing across pages and components.
2. Improve typography hierarchy everywhere.
3. Refine layouts for mobile, tablet, and desktop.
4. Fix any remaining visual inconsistencies.

### Phase 7: Final QA
1. Full visual audit of the entire app in black + orange theme.
2. Check hover/transition/animation quality and performance.
3. Verify skeleton loaders, toasts, and modals.
4. Responsive testing on multiple breakpoints.
5. Final polish pass.

### Recommended Implementation Order
1. Design tokens + theme foundation
2. Core components (buttons, cards, inputs, modals, toasts)
3. Sidebar / navigation
4. Motion system (hover, transitions, loaders, skeletons)
5. Page-by-page application
6. Spacing + typography refinement
7. Final QA and polish

### Definition of Done
- Entire app uses a consistent black + orange theme
- Components feel clearly upgraded and unified
- Motion is smooth and purposeful
- Spacing and typography are consistent
- Experience is strong on mobile, tablet, and desktop
- Product feels premium and cohesive end-to-end
