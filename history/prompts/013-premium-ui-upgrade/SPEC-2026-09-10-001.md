## Prompt

/sp.specify

Create a detailed functional specification for the Premium UI/UX Upgrade of the FitTrack application based on the constitution already defined.

### Feature: Premium UI/UX Upgrade (10.1)

#### 1. Overview
A complete visual and interaction upgrade of the entire FitTrack application. The goal is to transform the product into a premium, modern experience using a full black + orange design system, with improved components, motion, and consistency across every page.

#### 2. Global Theme
- Replace the existing color system with a complete **black + orange** theme.
- Primary background: deep black / near-black.
- Primary accent: vibrant orange.
- Remove all remaining green accents from the application.
- Ensure every page, component, and state uses the new theme consistently.

#### 3. Navigation
- Upgrade the sidebar / navigation to a modern, polished style.
- Improve active state, hover state, and overall visual hierarchy.
- Keep the left sidebar structure but elevate its look and feel.

#### 4. Core Components to Upgrade

**Cards**
- Refined borders, shadows, padding, and hierarchy
- Consistent style across Dashboard, Workouts, Nutrition, Analytics, etc.

**Buttons**
- Clear default, hover, active, and disabled states
- Consistent sizing, radius, and orange accent treatment

**Icons**
- Unified icon style and sizing
- Proper orange accent usage where needed

**Inputs & Forms**
- Improved visual style consistent with the new system

#### 5. Interaction & Motion
- Add refined hover effects on interactive elements
- Implement smooth transitions between states
- Add subtle page animations where appropriate
- Add loading animations for key actions
- Implement skeleton loaders for major data-loading states
- Improve toast messages (style + behavior)
- Improve modals (style, overlay, animation, hierarchy)

#### 6. Spacing & Typography
- Establish and apply a consistent spacing scale across the entire app
- Improve typography hierarchy (headings, body, labels, numbers)
- Ensure better readability and visual rhythm

#### 7. Responsive Design
- Ensure the upgraded UI works excellently on:
  - Mobile
  - Tablet
  - Desktop
- Navigation, cards, and layouts must adapt cleanly

#### 8. Scope of Application
This upgrade must be applied across all major areas of the product, including but not limited to:
- Dashboard
- Workouts
- Nutrition
- Progress / Analytics
- Goals
- History
- Profile
- Settings
- Notifications
- Reports

#### 9. Acceptance Criteria
- [ ] Full black + orange theme is applied everywhere
- [ ] No remaining green accents
- [ ] Sidebar/navigation looks modern and consistent
- [ ] Cards, buttons, and icons are clearly upgraded
- [ ] Hover effects and transitions are smooth
- [ ] Page animations, loaders, and skeleton states are implemented
- [ ] Toasts and modals are improved
- [ ] Spacing and typography are consistent
- [ ] Experience is strong on mobile, tablet, and desktop
- [ ] Overall product feels premium and cohesive
