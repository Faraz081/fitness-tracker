## Prompt

/sp.tasks

Break down the Notifications & Reminders feature into clear, sequential, and implementable tasks.

### 1. Foundation
- [ ] Add "Notifications" item to the left sidebar
- [ ] Create Notifications page route and basic layout
- [ ] Match the layout exactly with Dashboard (left sidebar + tight content area, minimal side gaps)
- [ ] Create Notification data model (id, type, title, message, timestamp, isRead, metadata)

### 2. Notification Creation
- [ ] Create Workout Completion notification when a workout is finished
- [ ] Create Goal Progress notification on significant progress
- [ ] Create Goal Completed notification when a goal reaches 100%
- [ ] Implement Workout Reminder logic
- [ ] Implement Meal Reminder logic
- [ ] Implement Goal Reminder logic
- [ ] Prevent duplicate notifications for the same event
- [ ] Respect user notification settings before creating any notification

### 3. Notifications Page
- [ ] Display notifications in chronological order
- [ ] Show clear visual difference between read and unread notifications
- [ ] Allow marking a single notification as read
- [ ] Add "Mark all as read" functionality
- [ ] Create empty state for when there are no notifications
- [ ] Optional: Show unread count badge on the sidebar

### 4. Notification Settings
- [ ] Create Notification Settings UI
- [ ] Allow enable/disable for each type: Workout completion, Goal progress, Goal completed, Workout reminder, Meal reminder, Goal reminder
- [ ] Persist settings
- [ ] Make sure the system fully respects the settings

- [ ] Connect notification triggers to existing workout and goal flows
- [ ] Ensure UI is visually consistent with Dashboard
- [ ] Remove any large empty side gaps
- [ ] Test read/unread behavior
- [ ] Test that disabled notification types are never sent
- [ ] Final responsive and UX check
