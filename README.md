# Fitness Tracker

MERN monorepo — `client/` (React + Vite) and `server/` (Node + Express).

- Install everything: `npm run install-all`
- Run both dev servers: `npm run dev` (server: `http://localhost:5000`, client: `http://localhost:5173`)

See **[`specs/001-setup-auth/quickstart.md`](./specs/001-setup-auth/quickstart.md)** for setup, configuration, and the end-to-end walkthrough.
